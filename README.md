# Atlas for Mac

Public downloads for Atlas, a local project knowledge and AI workspace.

## Install

Download [Atlas.dmg](https://github.com/LiquidInfinity/Atlas-downloads/releases/latest/download/Atlas.dmg), drag Atlas into Applications, and open it. Requires Apple Silicon and macOS 15.5 or newer. Signed by Infinite Reach LLC and notarized by Apple.

## Updates and data

Atlas 0.1.11 and later check this repository for updates. No GitHub account or access token is required. Versions 0.1.10 and earlier need a one-time manual installation to move from the old update service.

Your projects, captures, database, and credentials remain on your Mac. Replacing the app does not remove them. This repository contains release artifacts and matching dependency sources; it does not contain user projects or private sharing archives.
